# Personal Portfolio (Next.js + Tailwind + MDX)

Quick scaffold for a portfolio site that includes blog posts using MDX.

## Setup

Install dependencies and run locally:

```bash
npm install
npm run dev
```

Open http://localhost:3000

## Notes

- Edit pages in the `pages/` folder
- Add MDX posts to `posts/` — filename becomes the slug
- Deploy to Vercel for automatic Next.js support
